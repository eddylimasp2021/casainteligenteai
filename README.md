# Casainteligenteai

Crie um projeto em branco chamado "CASA INTELIGENTE": só a estrutura base e uma página inicial limpa com o nome do projeto centralizado. Nada além disso.

Sobre o projeto: # CASA INTELIGENTE AI — SMART HOME PLATFORM
## PROMPT MESTRE PARA DESENVOLVIMENTO NO LOVABLE

Crie uma plataforma SaaS/PWA completa de Casa Inteligente chamada **HomePulse AI**.

O sistema deve ser profissional, moderno, futurista, extremamente responsivo e preparado para funcionar em computador, notebook, tablet e celular.

NÃO criar apenas uma demonstração visual.

Criar uma aplicação funcional, com banco de dados SQL, autenticação, autorização, CRUD completo, APIs, automações, logs, notificações, arquitetura IoT e estrutura preparada para integração com dispositivos reais.

---

# 1. VISÃO

Base técnica: o padrão do Lovable (React + Vite + TypeScript + Tailwind + shadcn/ui). Organização: componentes em src/components, uma página por arquivo, dados de exemplo separados do visual. Visual: design system com as cores como tokens no Tailwind (nada de cor solta no código), tipografia com hierarquia clara, espaçamento consistente, responsivo pensado primeiro no celular, acessível (contraste, foco visível). A rota / tem que abrir funcionando. Não crie banco de dados nem login ainda.
